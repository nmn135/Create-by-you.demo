# 封印之殿 · 《第七天》 像素叙事 Demo v2

2D 像素无限叙事原型。一座永远停在第七天的城，3 个各有秘密的 NPC，玩家自由发言改变关系、传播流言、甚至敲响钟楼第十三下。

## 运行

需要 **Node.js 18+**。

- 方式一：双击 `启动demo.bat`（Windows）
- 方式二：命令行 `node server.js`

然后浏览器打开 <http://localhost:8890>。

## 操作

- `←` / `→` 移动，`E` 与最近的 NPC 交谈，`ESC` 离开
- 对话：输入文字后回车 / 点「说」
- 每个 NPC 有自己的"站点巡游"路线（钟楼、柜台、广场…），HUD 会显示他们现在在哪

## 核心机制（v2）

- **3 个 NPC**：守钟人·市长 / 当铺老板 / 说书人，各自有动机、秘密、和对你 4 维关系（信任/恐惧/好感/怀疑，低中高）。
- **隔墙有耳**：你说话时，站在旁边的 NPC 会直接听到——被听到的人头顶弹「!」，之后他会在对话里引用你。想保密？换个没人的地方说。
- **话会传播**：NPC 之间会凑在一起闲聊，把听来的话转述给别人。你留下的话会"活"在城里。
- **关系驱动世界**：你对所有人好，城变暖；你威胁所有人，城变红。
- **刻痕1「你开口了」**：第一次说出"剧本外"的话 → 钟楼敲响不存在的第十三下，全城沉默。
- **刻痕2「秘密上墙」**：把某人的秘密告诉不知道它的人 → 第二天，流言浪潮传遍全城。

## AI 对话配置（可选）

不配置也能玩（离线兜底回复）。要实时 AI 对话，需要 **Doubao（豆包）Ark API Key**：

1. 在本目录新建 `.env`，内容一行：
   ```
   DOUBAO_API_KEY=你的ark密钥
   ```
2. 重启 `server.js`

`.env` 已被 gitignore 排除，密钥不会进仓库；也可用环境变量 `DOUBAO_API_KEY`。

> 注意：对话走的是云端 LLM，回复需要几秒到十几秒（视模型负载），期间会显示「正在斟酌…」。
