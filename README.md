# 封印之殿（Sealed Hall）

一个基于 Three.js 的 3D 对话驱动游戏原型。

## 快速开始

- 双击根目录 `试玩启动.bat` —— 一键清理旧进程 + 启动服务器 + 每次全新开局
- 浏览器访问 <http://localhost:8080>
- 操作：`WASD` 移动 / `Shift` 奔跑 / `空格` 跳 / `Z` 蹲 / `C` 切换视角 / `E` 交互

## 目录结构

- `game-prototypes/3d-prototype/` — Three.js 3D 原型（浏览器）
- `game-prototypes/text-prototype/` — Python 终端文字原型
- `game-prototypes/assets/` — 模型与贴图资源
- `docs/` — 设计文档与调研
