# 对话交互设计构思

> 基于对开源对话驱动游戏生态的调研（ink / Yarn Spinner / Ren'Py / OpenMW / Dialogic 等），整理出封印之殿可借鉴的交互设计。**引擎与 UI 分离 + 节点图数据结构**是主流范式。

## 一、互动按键设计

开源惯例：**接近 → 显示提示 → 互动键 → 对话框 → 空格推进 → 数字键选分支**

| 操作 | 惯例 | 封印之殿实现 |
|------|------|-------------|
| 接近 NPC | 检测距离 | 玩家靠近 NPC 1.5m 内，头顶显示互动提示「按 E 交谈」 |
| 互动键 | E（Skyrim）/ 空格 | **E 键**进入对话（第一/第三人称下） |
| 推进台词 | 空格/Enter | **空格**推进下一句（保留现有） |
| 选分支 | 数字键 1/2/3 | **数字键**选对话选项（当有分支时） |
| 自由输入 | - | 保留现有**输入框自由文本**（AI 对话模式） |

**核心**：两种对话模式并存——
1. **AI 自由对话**（现有）：输入框打字，AI 生成回复
2. **节点分支对话**（新增）：E 键触发后显示预设选项（数字键选），适合关键剧情节点

## 二、多 NPC 对话设计（一对一 + 当前说话人标识）

开源几乎都是**一对一 + speaker 标识**：

- **Yarn Spinner / Dialogic**：`角色名: 台词` + 头像
- **Ren'Py**：侧头像 + 说话人高亮
- **OpenMW**：激活 NPC → 话题列表窗口（topic 关键字高亮）

**封印之殿实现**：
1. **对话目标锁定**：E 键触发后锁定当前 NPC（其他人不再插话，除非连锁反应）
2. **说话人头像**：对话面板顶部显示当前 NPC 头像（用模型截图/图标）+ 名字
3. **在场 NPC 反应**：公开对话时，其他 NPC 的关键反应以「⚡ 连锁反应」插卡出现（现有系统已支持）
4. **对话相机**：开始对话时相机 lerp 推近到说话 NPC 头部 + 朝向，结束回位

## 三、对话数据结构升级（线性数组 → 节点图）

现状：`dialogueData[]` 线性数组（speaker/text/system）

升级方向（借鉴 **ink** 节点图）：

```
对话节点 {
  id: "baruk_secret_1"
  speaker: "baruk"
  条件: trust_baruk > 50
  台词: "......"
  分支: [
    { 选项: "继续说", 跳转: "baruk_secret_2" },
    { 选项: "沉默", 效果: trust_baruk + 5, 跳转: "end" }
  ]
}
```

- AI 生成内容挂**叶子节点**，节点图管分支/条件
- 状态机裁决（现有 Python）决定走哪条分支
- 适合关键剧情节点（失言、秘密揭露、结局分支），日常对话仍用 AI 自由模式

## 四、对话 UI 升级

1. **居中对话框**：当前说话人头像 + 名字 + 台词
2. **分支选项**：数字键选择，高亮悬停
3. **E 键提示**：靠近 NPC 显示「按 E 交谈」（第一/第三人称）
4. **对话记录保留**：侧边栏保留完整记录（现有），居中框显示当前对话

## 五、实施优先级

1. **E 键互动 + 接近提示**（低难度，立刻有感）
2. **对话相机推近**（中难度，增强沉浸）
3. **节点分支对话**（中高难度，需数据结构升级）
4. **说话人头像**（低难度，UI 增强）

## 七、骑砍 2 深度调研补充（2026-08-11 二次调研）

> 针对用户指正，系统性调研骑砍 2 及同类游戏的对话设计。**结论：骑砍 2 的对话结构高度值得借鉴，远超之前判断。**

### 骑砍 2 可借鉴的三件套
1. **中心-分支节点树**：进对话先落「打招呼」中心节点，再按类展开（询问消息/交易/招募/关系/说服/告别）。→ 解决 AI 自由对话无导航锚点问题：日常自由聊，关键操作（交易/告别/套话）走话题分支
2. **Relation 好感度驱动**：-100~100 决定节点可见性、说服成败、交易价格。→ 映射到我们的信任度门槛
3. **说服计量器**：骑砍独有说服机制。→ 可抄成 AI 说服进度条

### 落地建议（下一轮）
- UI：**不切全屏**，保持游戏画面 + 底部对话日志（流式打字）+ 顶部意图快捷按钮（交易/告别）作骑砍式锚点
- 视角：对话开始推近到对方特写 + 锁定视线
- 触发：接近半径 + 交互键（骑砍/老滚通用）
- 多 NPC：只与触发者对话，其余围观（AI 后置注入旁白）
