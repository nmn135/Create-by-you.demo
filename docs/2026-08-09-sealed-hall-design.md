# 封印之殿（Sealed Hall）

## 一、项目概述

### 1.1 核心概念

一款以**自然语言对话**为核心驱动的 3D 叙事游戏。玩家在对话框中自由输入文字，通过对话改变 NPC 之间的关系、揭露秘密、操纵世界线走向。

### 1.2 核心验证目标

> **"玩家能通过说话改变世界"这个机制本身好不好玩。**

重点在于对话系统和关系网的深度，而非地图规模或战斗系统。

### 1.3 灵感来源

- 《骑马与砍杀 2：霸主》——开放世界沙盒、派系政治、NPC 个人关系网
- AIInfluence 模组——AI 实时对话替代预制台词，NPC 动态记忆和情绪
- 经典"暴风雪山庄"模式——封闭空间中人物关系的高度浓缩

### 1.4 技术路线

- **第一阶段**：Obsidian vault 内完成完整设计文档（当前阶段）
- **第二阶段**：Three.js + AI API 的浏览器单文件 3D 原型
- **渲染**：Three.js（纯浏览器，单 HTML 文件即可运行）
- **AI 层**：DeepSeek V4 Pro（意图解析）+ DeepSeek V4 Flash（回复生成）
- **逻辑层**：纯 JavaScript 确定状态机
- **3D 资产**：Mixamo（角色 + 动画）+ Sketchfab / Poly Haven（场景）

## 二、世界观

### 2.1 封印之殿

千年前，半神法师 **艾瑟林（Aetherin）** 在大陆中心建造了一座殿堂。她设下预言：当人类、精灵、矮人、兽人四族同时抵达殿心，殿的封印将解除——释放能满足一切心愿或毁灭一切贪念的力量。

千年后，四族探险者找到了它。殿堂在他们踏入的瞬间封死所有出口。殿中央浮雕开始发光，一个声音在每个人脑海中响起：

> *"心中所念，即为钥匙。证明你们的灵魂值得。"*

### 2.2 守护灵

艾瑟林的意识残片。不是人，没有固定形态（发光的人形轮廓）。守护灵会根据 NPC 间的对话和情绪调整"认可"的判定标准。它有千年的孤独、自己的好恶、会被触动也会被欺骗。

### 2.3 玩家

第五个进入殿的人——迷路进来的，不属于任何与这座殿有宿怨的种族。一千年来的第一个"无关之人"。守护灵对你格外关注，通过你观察和试探。

## 三、角色

### 3.1 莉安娜（Liana）——精灵学者

| 属性 | 内容 |
|------|------|
| **表面目的** | 带回古代知识，发表论文扬名立万 |
| **深层秘密** | 殿的建造者艾瑟林是她的祖先。她的血脉就是钥匙的一部分 |
| **防御方式** | 学术傲慢——把一切拉成知识的距离 |
| **失言模式** | 智识优越被刺破时崩溃，学术框架瓦解后只剩愧疚 |
| **守护灵态度** | 血脉共鸣 + 失望——千年后自己的后裔变成了学术机会主义者 |

### 3.2 巴鲁克（Baruk）——矮人佣兵

| 属性 | 内容 |
|------|------|
| **表面目的** | 分钱，只要自己那份 |
| **深层秘密** | 氏族曾被迫为奴建造此殿，完工后被精灵屠杀。他发现了墙上矮人工匠的矿工密语求救暗语 |
| **防御方式** | 沉默和冷笑 |
| **失言模式** | 积压爆发——准确追问到第三轮后，低声一口气把真相说出，语气疲惫而非愤怒 |
| **守护灵态度** | 愧疚 + 回避——艾瑟林当年默许了屠杀，暗语是她唯一能做的赎罪 |

### 3.3 玛格丽特（Margaret）——人族牧师

| 属性 | 内容 |
|------|------|
| **表面目的** | 奉教会之命销毁殿中的"异端遗产" |
| **深层秘密** | 年轻时爱上术士，术士被教会烧死在她面前。她加入教会不是信仰而是恐惧。教会当年还拒绝庇护 Baruk 的氏族——她参与了会议，选择了沉默 |
| **防御方式** | 职业性完美面具 |
| **失言模式** | 防御过载断裂——被触碰到"旁观者罪责"时轻声崩溃 |
| **守护灵态度** | 敌意——教会追杀过艾瑟林一生 |

### 3.4 罗格·铁牙（Rog Ironfang）——兽人战士

| 属性 | 内容 |
|------|------|
| **表面目的** | 寻找祖传战斧，证明自己配继承部落 |
| **深层秘密** | 父亲不是战死的——是他在战斗中失控误杀。他是逃出来的 |
| **防御方式** | 沉默——最简单的防线 |
| **失言模式** | 被温柔击溃——被善待和接纳时说出口，不是压力是解脱 |
| **守护灵态度** | 好奇——唯一没有参与建殿历史纠葛的种族，最温和对待 |

## 四、关系网

### 4.1 NPC 两两关系

| 关系 | 表层 | 深层 | 可操作裂缝 |
|------|------|------|-----------|
| **莉安娜 ↔ Baruk** | 互相瞧不起 | 祖先合作建殿→精灵屠杀矮人工匠 | ① 道歉 vs 抵赖 ② 公开指控 vs 沉默 ③ 需要合作才能激活殿核心 |
| **莉安娜 ↔ 玛格丽特** | 礼貌客套 | 艾瑟林是精灵偶像也是教会头号异端。玛格丽特奉命销毁其遗产 | ① 提前告诉莉安娜真相→引爆 ② 缓冲冲突 ③ 玛格丽特可能叛教保护遗产 |
| **莉安娜 ↔ 罗格** | 微妙恐惧 vs 漠然 | 罗格的部落杀了莉安娜的导师，用的精灵短剑是莉安娜送的临别礼物 | ① 指出短剑=炸弹 ② 罗格不想延续仇恨 ③ 最有希望的和解线 |
| **Baruk ↔ 玛格丽特** | 矮人厌恶牧师 | 教会拒绝庇护 Baruk 的氏族，玛格丽特参与了当年的会议 | ① 玛格丽特有愧疚 ② Baruk 不知道她与那件事有关 |
| **Baruk ↔ 罗格** | 互相尊重——最真实的友谊胚子 | 共同经历：矿道、黑暗、被文明世界排斥 | ⚠️ 最不该破坏的线。种族对立可能迫使他们站到对立面 |
| **玛格丽特 ↔ 罗格** | 恐惧 vs 习惯 | 两个背负罪孽的人——罗格是行凶者，玛格丽特是沉默的旁观者 | 最难被玩家触及，但可能产生最深刻的情感冲击 |

### 4.2 冲突结构图

```

                莉安娜 ←——→ Baruk
               （精灵）      （矮人）
                  |  \        /  |
      祖先真相    |   \      /   |  教会驱逐
                  |    \    /    |
                  |     \  /     |
      学术vs信仰  ↓      \/      ↓
                玛格丽特 ←——→ 罗格
                （人族）  同类罪孽  （兽人）
                  |                  |
                  |   共同黑暗       |
                  +—————盟友胚芽————+
```

## 五、对话系统

### 5.1 混合架构

```
玩家输入自由文本
       │
       ▼
  ┌──────────┐
  │ 意图解析器 │  ← AI（LLM API）
  │ 理解：态度 │
  │ 对象、行为 │
  └────┬─────┘
       │ 结构化意图
       ▼
  ┌──────────┐
  │ 状态机裁决 │  ← 纯代码（确定性）
  │ 检查关系值 │
  │ 触发条件  │
  └────┬─────┘
       │ 裁决结果 + 预设方向
       ▼
  ┌──────────┐
  │ 回复生成器 │  ← AI（LLM API）
  │ 生成 NPC  │
  │ 自然语言  │
  └──────────┘
```

### 5.2 意图类型

| 意图 | 示例 |
|------|------|
| `ask_backstory` | 你为什么会来这座殿？ |
| `probe_conflict` | 你和那个牧师好像不太对付？ |
| `reveal_secret` | 告诉你一件事，Baruk 其实是…… |
| `persuade` | 你应该去和她谈谈 |
| `accuse` | 你在撒谎 |
| `take_sides` | 我这次站在你这边 |
| `sow_discord` | 你知道他背地里怎么说你吗 |
| `offer_comfort` | 你不必自责 |
| `ask_favor` | 你能帮我看一下这个符文吗 |
| `stay_silent` | 选择沉默 |

### 5.3 NPC 状态模型

```
NPC 状态 {
  对玩家信任度: 0-100
  对其他 NPC 态度: { Liana: -30, Margaret: 10, Rog: 45 }
  当前情绪: calm / tense / angry / vulnerable / hopeful
  已知秘密: [ 列表 ]
  已触发事件: [ 列表 ]
}
```

## 六、悄悄话系统

### 6.1 两种对话模式

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| **公开对话** | 所有 NPC 可听到并可插话 | 了解信息、公开表态、引发群戏 |
| **悄悄话** | 单独拉一旁，第三方听不到内容但知道你们在密谈 | 欺骗、密谋、勒索、私下交易 |

⚠️ **守护灵始终能听到一切悄悄话。** 悄悄话越多 → 守护灵越了解你的真面目。

### 6.2 可获取/骗取的内容

| 类型 | 难度 | 例子 |
|------|:---:|------|
| **信息** | 🟢 | 套出 NPC 不愿公开的秘密 |
| **物品** | 🟡 | 钱、钥匙、信物、武器 |
| **承诺** | 🟡 | NPC 站你这边 / 投票支持 / 不揭发 |
| **背叛** | 🔴 | 让 NPC 背叛盟友或原则 |

### 6.3 约束规则

```
是否接受悄悄话请求 = f(
  信任度,           // 基础门槛
  感知利益,         // NPC 觉得有利可图吗
  NPC性格抵抗力,    // Rog > Margaret > Liana > Baruk
  被索取物重要度,   // 钱包 ≠ 祖传战斧
  守护灵暗中评价    // 环境变化暗示 NPC "小心这个人"
)
```

## 七、失言系统

### 7.1 核心原则

玩家永远看不到数值条。系统的任务是让"恰好触发"的瞬间感觉像玩家的功劳。

### 7.2 秘密属性

| 属性 | 含义 |
|------|------|
| **防御等级** | NPC 平日有多严防（1-100） |
| **情绪钥匙** | 什么情绪下防御下降 |
| **痛点短语** | 哪些词会刺破防线 |

### 7.3 失言公式

```
失言概率 = (
  (100 - 防御等级)
  + 信任度奖励               // 每 10 点 = +5%
  + 情绪奖励/惩罚            // angry +30%, vulnerable +25%
  + 追问累积                // 第 2 次 +15%, 第 3 次 +30%
  + 痛点短语命中             // 每命中一个 +10%
  - 在场威胁                // 涉及对象在场 -40%
) / 100
```

### 7.4 各 NPC 失言模式

| NPC | 模式 | 描述 |
|-----|------|------|
| **Baruk** | 积压爆发 | 追问至第三轮 → 低声一口气说出全部真相，语气疲惫 |
| **玛格丽特** | 防御过载断裂 | 触及"旁观者罪责" → 轻声崩溃 |
| **莉安娜** | 智识优越被刺破 | 学术框架瓦解 → 剩余愧疚和恐慌 |
| **罗格** | 被温柔击溃 | 被善待和接纳 → 说出最难启齿的事 |

## 八、出场顺序

| 阶段 | 登场 | 关键事件 | 玩家学到 |
|:---:|------|---------|---------|
| **0** | 玩家 + 守护灵 | 独处，守护灵解释规则 | 基础世界观 |
| **1** | + 罗格 | 兽人迷路闯进，粗鲁坦诚 | 第一个对话练习 |
| **2** | + Baruk | 矮人进殿盯着墙，与罗格聊上 | 发现第一个谜团（墙上暗语） |
| **3** | + 莉安娜 | 精灵认出建筑风格，Baruk 停止看墙 | 矮人与精灵间的紧张 |
| **4** | + 玛格丽特 | 脸上有血，守护灵剧烈反应 | 所有矛盾引爆 |

玩家每充分对话后可选择"等待"推进阶段，有控制感。

## 九、可视线索

### 9.1 环境叙事提示

进入对话前，系统根据当前状态自动推送一条感知提示：

> 🗨️ *Baruk 的眼神刚才在莉安娜进门时闪了一下——他一定认识她，但不想让她知道。*

### 9.2 NPC 微反应

不是 3D 动画，而是直接在叙事文本中描述：

> *（Baruk 的嘴角动了动。不是笑，是某种被忍住的东西。）*

### 9.3 对话记忆面板

可随时拉开的侧边栏，显示已知关键信息，防止被信息淹没。

## 十、剧情分支

### 10.1 结局方向

| 结局 | 触发条件 | 世界线结果 |
|------|---------|-----------|
| **真理之殿** | 莉安娜承认真相、Baruk 接受道歉、四人合作激活殿 | 艾瑟林力量释放，四大种族历史重写 |
| **血债血偿** | Baruk 公开暗语、莉安娜抵赖、种族对立激化 | 殿成战场，永久封印，四人困于殿中 |
| **新火种** | Baruk 和罗格的友谊被保护、玛格丽特背叛教会 | 矮人+兽人联盟从殿内延伸到殿外 |
| **谁都没被救赎** | 玩家逐一挑拨所有关系 | 守护灵暴走，殿崩塌，玩家被送出——"你无关，你走吧" |
| **弑神者** | 玩家成功欺骗守护灵，利用它的孤独和好奇 | 获得神力，代价是守护灵——艾瑟林最后的意识永远消散 |

### 10.2 关键分支点

| 阶段 | 选择 | 走向 |
|------|------|------|
| 阶段 2：Baruk 看墙 | 公开问他 → 提前引爆 / 悄悄话 → 获得信息但记账 | Baruk 信任方向 |
| 阶段 3：莉安娜入场 | 透露 Baruk 异常 → 被迫对话 / 沉默 → 压力积累 | 怒发 vs 冷发 |
| 守护灵首次被激怒 | 帮玛格丽特 → 守护灵动摇 / 沉默 / 加入敌视 | 道德坐标偏移 |
| 罗格+Baruk 友谊萌芽 | 保护 → 可能联手 / 挑拨 → 唯一和平纽带断裂 | 核心天平 |
| 终局前夜 | 对守护灵说最后一句话 | 决定最终评判 |

## 十一、技术方案

### 11.1 技术栈

| 层 | 技术 | 理由 |
|---|------|------|
| 3D 渲染 | Three.js | 纯浏览器，单 HTML 文件 |
| AI 意图解析 | DeepSeek V4 Pro | 理解准确度最关键 |
| AI 回复生成 | DeepSeek V4 Flash | 生成量大，用便宜的 |
| 状态机 | 纯 JS 对象 | 确定性，不依赖 AI |
| 角色 + 动画 | Mixamo（Adobe） | 免费已绑骨 |
| 场景 | Sketchfab / Poly Haven | 免费可商用 CC0 |

### 11.2 场景布局

```
          [入口]（封死）
    ┌──────────────────┐
    │   精灵区          │  藤蔓、古文字、书架残骸
    │   （莉安娜）       │
    │                    │
    │   中央             │  守护灵悬浮 + 浮雕核心
    │                    │
    │  矮人区   兽人区   │  矮人：矿脉纹理、符文暗语
    │ （Baruk） （罗格）  │  兽人：简单粗糙石质
    │                    │
    │   人类区           │  教会圣徽被灼烧痕迹
    │   （玛格丽特）      │
    └──────────────────┘
```

### 11.3 摄像机与交互

- 第三人称自由旋转
- 对话时自动推近
- NPC 情绪变化时位置迁移（生气→角落、和解→走近）
- 环境反馈：守护灵光芒、符文、屏幕色温

| 记忆类型 | 持久性 | 举例 |
|---------|:---:|------|
| 对话记忆 | 永久 | "玩家对 Baruk 说过'我理解矮人受的苦'" |
