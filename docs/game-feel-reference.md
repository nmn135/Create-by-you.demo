# 封印之殿 — 游戏手感参数速查（12:00 调参用）

> 位置：`3d-prototype/src/fps_controller.js`。改完**刷新浏览器即可生效**（服务器无需重启，前端参数在构造函数里）。
> 改后建议跑 `cd /d/tools/playwright && node cdp_smoke_1200.js` 确认没改坏。

## 一、当前参数（08-12 基准）

| 手感维度 | 参数 | 当前值 | 行号 | 作用 |
|------|------|:---:|:---:|------|
| 行走速度 | `moveSpeed` | **4.0** m/s | 34 | WASD 默认速度 |
| 奔跑速度 | `runSpeed` | **7.5** m/s | 35 | Shift 奔跑（walk 动画 ×1.8 加速） |
| 蹲伏 | `speed *= 0.5` | 走速×0.5 | 366 | 眼高降到 1.6×0.55 |
| 跳跃初速 | `velY = 5.2` | **5.2** | 225 | 空格起跳速度 |
| 重力 | `gravity` | **14** | 382 | 落地手感（越大越沉） |
| 起步加速 | `accel` | **14** | 44 | 起步顺滑度（越大起步越跟手） |
| 松键减速 | `decel` | **12** | 45 | 轻微滑行（越小越滑） |
| 基础 FOV | `baseFov` | **50** | 46 | 相机视角 |
| 奔跑 FOV 扩张 | `baseFov + 9` | +9 | 434 | 跑动速度感 |
| 蹲伏 FOV 收缩 | `baseFov - 5` | -5 | 434 | 蹲下视角 |
| 鼠标灵敏度 | `0.0022 × sensitivity` | 0.0022 | 263 | 第一人称水平转向 |
| 垂直灵敏度 | `0.005 × sensitivity` | 0.005 | 274 | pitch 上下（有 ±1.25 限位） |

> `sensitivity` 来自设置持久化（`sealed_settings`），游戏内可调；其余参数走代码。

## 二、用户反馈 → 改哪里（一句话对照表）

| 用户说 | 改 | 建议尝试 |
|------|------|------|
| "走得太慢/太快" | `moveSpeed` | 4.0 → 3.2 或 4.8 |
| "跑起来太快/慢" | `runSpeed` | 7.5 → 6.5 或 8.5 |
| "跳得太飘/太重" | `velY` + `gravity` | 飘 → 降 velY 到 4.8；重 → 降 gravity 到 12 |
| "起步肉/发飘" | `accel` / `decel` | 肉 → accel 14→18；发飘 → decel 12→16 |
| "转弯发晕" | `baseFov` 或灵敏度 | FOV 50→55 缓解晕动；灵敏度降 20% |
| "跑动太晃" | `baseFov + 9` | +9 → +5（减少视觉冲击） |
| "镜头太灵敏/迟钝" | 游戏内灵敏度设置 | 0.0022 基础值不建议改，用设置项调 |

## 三、快速应用方法

1. 编辑 `src/fps_controller.js` 对应行 → 保存
2. 浏览器**刷新** `http://localhost:8080`（前端参数，无需重启 server.py）
3. 试 30 秒感受 → 再微调
4. 确定后跑一键冒烟回归

## 四、提醒

- 这些参数是**全局手感基线**；若未来支持每角色/场景差异化，再做成配置对象（当前刻意保持简单）
- 手感调优是本轮**优先方向 A**，12:00 试玩反馈是主要依据
